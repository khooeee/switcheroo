# Switcheroo

## North Star

High productivity keyboard friendly ACP coding agent that blends the best of CLI coding agents & chat UIs like ChatGPT, Claude, etc.

# Metrics

- Speed of slow operations (e.g. creating a new session)

# Constraints

- A central feed of events aka Switchboard (I liked firstmate, but it was token heavy & slow to react)
- A simple UI more similar to ChatGPT, Claude, Gemini chat, etc. is much easier to work with than what a lot of ADEs do today.
- Has Zen mode (hides details & tool calls but can inspect if need be)
- It obeys keyboard shortcuts that are normally found in coding agent CLIs (Control + C, Control + D, Escape key, etc.).
